A one-line comedy patch note for a bug in real life, written for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty: after you bite your cheek once, the tongue saves the location and returns to bite the exact same spot at every meal for a week — shipped as release note v2.7.1. The program writes exactly that one line (152 characters) to `entry.txt`, and an AI comedy judge compares it against the other entrants' patch notes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

That writes the patch note to `out/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to any local folder to see it; in the grading sandbox it defaults to `/output`).
